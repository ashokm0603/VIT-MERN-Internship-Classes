HTML Tags : 

    -> tag are pre-define words which are enclosed with both opening and closing angular brackets 

    ->Types : 
        1. paired tags 
            ->any tags having opening and closing is a called paired tags
            ->Ex: 
                1. heading tags 
                        <h1>heading tags-1</h1>
                        <h2>heading tags-2</h2>
                        <h3>heading tags-3</h3>
                        <h4>heading tags-4</h4>
                        <h5>heading tags-5</h5>
                        <h6>heading tags-6</h6>

                2. formatting tags : 
                    Ex: 
                         1. <b></b>
                         2. <strong></strong>
                         3. <u></u>
                         4. <i></i>
                         5. <em></em>
                         6. <mark></mark>
                         7. <sub></sub>
                         8. <sup></sup>
                         9. <center></center>
                         10. <strike></strike>
                         11. <marquee></marquee>


                3. other tags 
                    Ex: <p> </p>
                        <div></div> 
                        all sematic tags 
                        all media



        2. unpaired tags /self closing tags
            ->any tags having only opening is a called unpaired tags
            Ex: <br> , <hr> , <input/> ,<col> , <meta>, <DOCTYPE>

HTML Attributes: 
----------------
    ->Additional information given to the tags is called Attributes
    ->Every ELEMENTS having Attributes
    ->Attributes are always in static tags(opening)
    ->Attributes are key and value paired

Ex: <h1  align="center style="color:red"> Attributes Example </h1>

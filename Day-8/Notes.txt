Tokens : 
--------
    ->Tokens are the smallest units in the code 
    ->Types : 
        1. Identifiers 
            ->Identifiers are the names given to JS code 
            ->The place of Identifiers we can not use keywords
            Ex: 
                    variable name , class names , function names 

        2. keywords 
            ->keywords are the pre define words 
            ->In JS we have total 66 keywords 
                Ex: abstract , assert , boolean , break , byte , class , const , constant , continue , do , double , enum , else, finally , final , if, implements , import , instanceOf , try , public, private , typeOf ...

        3. literals 
                ->literals are the values given to JS code 

        4. operators 
            ->operators are the symbol's used to perform some operations on operands 
            ->Ex: 10+20 

            Type:
             1. Athematic operators (+,-,*,/,%. **)
             2. Assignment operators (=,+= ,-=,/=,*=,%=)
             3. relational operators (>,<,>=,<=)
             4. comparison operators (!=, ==, ===)
             5. shift operators(>>,<<)
             6. logical operators(&& ,|| , !)
             7. bitwise operators( & ,|, !)
             8. Unary operators (++ ,--)
             9. ternary operators (condition ? expr1: expr2)


        5. separators 
            ->separators are used to given code 
                Ex: , . , :,;, "" ,'' ,`` , [],{ },() ,<>

        6. comments
            ->comments are used to comments the code 
            ->Types 
                1. single line comments             // 
                2. multi line comments              /*

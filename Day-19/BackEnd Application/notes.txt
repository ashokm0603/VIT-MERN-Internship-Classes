Node Js : 
----------
    ->Node Js the Server side programming language that used to run javascript outside the browser 
    ->Node Js will create Run Time Server side Environment to run JS code 
    ->by default Node Js having V8 Javascript Engine 
    ->Using Node we create API's and also create Server without express js 


npm (node package manager): 
---------------------------
    ->npm is used to install external packages 


Import and export modules in Node Js 
-------------------------------------
    1. Import modules 
            ->using require() we can Import modules/ files 

    2. export modules: 
            ->using module.exports   we can export modules/files

Express JS : 
-------------
    ->Express js the open source backend web application framework for Node Js 

    Core Features: 
        1. Robust Routing System : specific URL (GET , POST , PUT , DELETE, PATCH) 
        2. Middleware Architecture : 
        3. Template Engine Integration
        4. Minimal boilerplate
        5. We can Build application Rapidly


Steps to SetUp backend using Express Js: 
-----------------------------------------
    1. npm init -y
    2. install Express package using command "npm install express"


To test Api : 
    1. http method

    4. body json data (post , put )

components In React :
-----------------------
    ->components are the smallest UI blocks 
    ->Types 
        1. Class based Components 
            ->Any Components which is declear by 'class' keyword is called as class based component
            ->CBC also called as a StateFull Component in CBC states will present 
            ->CBC contains constructors , super keyword , this keyword , render methods 
            ->in CBC life Cycle Methods are present 


            Syntax: 
                import {Component} from 'react';
                class ComponentName extends Component{
                        render(){
                            return (
                                here write html code
                            )
                        }
                }
                export default ComponentName


        2. Functions Based Components
            ->Any Components which is declear by 'function' keyword is called as function based component
            ->FBC also called as a StateLess Component in FBC states are not present 
            ->FBC not  contains constructors , super keyword , this keyword , render methods 
            ->in FBC life Cycle Methods are not present


            ->Syntax 1: 
                function ComponentName(){
                    return(
                        here write html code 
                    )
                }
                export default ComponentName

            ->Syntax 2: 
                const ComponentName=()=>{
                    return(
                        here write html code 
                    )
                }
                export default ComponentName

            ->Syntax 3: 
                const ComponentName=function(){
                    return(
                        here write html code 
                    )
                }
                export default ComponentName

States In React : 
-----------------
    ->States are used to hold the data/values 
    ->States are mutable in nature 
    ->States are present only in CBC 
    
    1. States in CBC : 
      ---------------
        -> Syntax : 
              import {Component} from 'react';
                class ComponentName extends Component{
                    constructor(){
                        super(); 
                        this.state=value
                    }

                        render(){
                            return (
                                here write html code
                            )
                        }
                }
        -> To mutate State values in CBC there is a method called 'setState()'

    2. States in FBC : 
      ---------------
        ->In function we can  not declear states directly 
        ->in the react version 16.8 they introduced 'Hooks' concept

useMemo() :
-----------
    ->useMemo() is react Hook that memorizes the results/values of a calculation and  only recalculation ot when its dependencies changes 


    Syntax : 
       const variableName=useMemo(()=>{
            return calculation;
        }   , [dependencies]) 


     Why use useMemo: 
        ->Improves performance by avoiding unnecessary calculation
        ->UseFul When a Component re-renders frequently
        ->presents expressive functions form running on every render 


Context API : 
-------------
    ->useContext is a React Hook that allows a component to consume values from Context without using props.
   ->It helps avoid props drilling, meaning you don’t need to pass data through multiple nested components.

   Syntax : 

	step 1: Create context
			const MyContext = createContext();


	step 2: Provide context
			<MyContext.Provider value={data}>
    				<ChildComponent />
			</MyContext.Provider>


	step 3:Consume Context using useContext
			const value = useContext(MyContext);


Useful when:

    1. Sharing state globally (theme, user info, cart data, etc.)
    2. Multiple components need the same data
    3. You want cleaner and easier-to-maintain code


useCallBack: 
    ->useCallBack() is a React Hook that "memorizes a function " and returns the same function reference b/t renders unless its dependencies changes

    Syntax : 
       const variableName=useCallBack(()=>{
            return function;
        }   , [dependencies]) 

    UseFul When : 
        1. Prevents unnecessary recreation of the function of every render
        2. UseFull when passing function to child components warped  with React.memo 
        3. Helps Improves performance by avoiding unnecessary child-render 


useEffect :

    UseFul When :
